# Check before submitting

The write-up, video script and publishing steps in this folder are drafts written by the developer (an AI) from the code. Every factual claim in them is listed here. A person on the team should confirm each one, or correct the draft, before anything is submitted.

## Do these first: only a person on the team can

A judge who opens the repository sees an empty project. Either switch the default branch to `relight` (GitHub: Settings, General, Default branch), or fast-forward `main` (`git push origin origin/relight:refs/heads/main`, no force needed), or both. Then open the repository in a private window and check that the Relight README shows.
- [ ] **Record the video**, 3:00 or less, from video-script.md.
- [ ] **Read the hackathon's own pages or ask in Discord**: is Gemini's image model or any sponsor tool required (Enhance is the only place it is used, and it is off in the demo); is the video required as well as the live link; is the deadline EDT or AoE; where is the submission made; must the use of an AI coding assistant be disclosed; does anyone have to present on Monday.
